# UCP Clubs Portal

A small informational website that introduces student clubs at the University of Central Punjab (UCP) and helps new students get involved in campus activities.

Built collaboratively with Git and GitHub for DevOps Fundamentals (Fall 2026), Assignment 01.

## Pages

| Page | Description | Owner |
|------|-------------|-------|
| index.html | Home page and introduction to campus clubs | Team Lead |
| clubs.html | Club categories with short descriptions | Member 1 |
| events.html | Upcoming club events | Member 2 |
| join.html | How to join a club | Member 3 |
| highlights.html | Club achievements and highlights | Member 4 |

## How to view

Open src/index.html in any web browser.

## Branching strategy

| Branch | Purpose |
|--------|---------|
| main | Production ready code (3 approvals required) |
| develop | Active development (2 approvals required) |
| feature/<page-name> | One branch per page, merged into develop through pull requests |
| release/v1.0 | Testing (QA) before merging into main |
